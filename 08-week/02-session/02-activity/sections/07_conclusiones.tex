\section{Conclusiones}
En este trabajo se desarrolló SGH, un sistema de gestión de horarios académicos usando Next.js, Tailwind CSS, Spring Boot y React Native. La integración vía APIs REST demostró eficiencia y escalabilidad. Los resultados confirman que frameworks modernos facilitan desarrollo rápido y mantenible. Futuras mejoras incluyen optimización de algoritmos, mayor seguridad y expansión a microservicios distribuidos.
