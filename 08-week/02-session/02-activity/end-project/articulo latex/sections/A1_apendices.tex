\section{Descripción de componentes del Sistema de Tickets}
Aplicación web (React): Interfaz para administración, gestión y visualización de tickets.

Servidor backend (Laravel): API REST para lógica de negocio y persistencia.

Aplicación móvil (React Native): Consulta de tickets en dispositivos Android.

Base de datos (MySQL): Almacenamiento de datos de tickets, técnicos, categorías, usuarios.
